## Ветвление
`main` — стабильная версия, `develop` — сборка команды, `feature/имя` — личные ветки участников.
Изменения попадают в `develop` только через Pull Request с ревью тимлида.

## Состав проекта
- `data.js` — исходные данные группы
- `letters.js` — буквенные оценки
